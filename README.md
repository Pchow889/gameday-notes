# Gameday Notes

Gameday prep sheet for NFL QB1–2, RB1–3, WR1–5 and TE1–3 on all 32 teams: birthdays, milestones in reach, all-time leaderboard moves, 2026 ranks, revenge games (previous team / 2 teams ago, with stats there), contract bonuses in reach, off-field news, and family-loss and wedding anniversaries.

Static site, deployed by Vercel on every push to `main`.

## Files

| File | What it is |
|---|---|
| `index.html` | The page, including the Joey / Guest login |
| `data.js` | Everything the page shows, generated by `build.py` |
| `build.py` | Pulls nflverse data (depth charts, stats, schedule, birthdays) and merges the four JSON files below into `data.js` |
| `news.json` | Off-field personal news, researched and sourced |
| `anniversaries.json` | Dated family losses and weddings, researched and sourced |
| `bonuses.json` | Publicly reported 2026 contract incentives; thresholds are checked against 2026 stats |
| `pfr_leaderboard.json` | Pro Football Reference "upcoming milestones and leaderboard movement" |
| `robots.txt` | Keeps search engines from listing the site |

## Updates (on request)

Nothing runs on a schedule. Say **"refresh"** to Claude and it runs everything on demand, in one go:

1. Re-research the hand-sourced files: off-field news (`news.json`), family-loss and wedding anniversaries (`anniversaries.json`), contract incentives (`bonuses.json`) and the Pro Football Reference milestones page (`pfr_leaderboard.json`)
2. Rebuild with `python3 -I build.py .`, which pulls fresh nflverse depth charts, stats, schedule and birthdays and writes `data.js`
3. Commit and push to `main`; Vercel redeploys

To rebuild by hand without re-researching: `python3 -I build.py .` then commit `data.js` and the JSON files.

## Login

Guest opens without a password. Joey's password is checked in the browser against a SHA-256 hash, which keeps it out of the page source but is not real security — the site is public to anyone with the link.
